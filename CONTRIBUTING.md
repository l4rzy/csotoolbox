# Contributing

Contributions are welcome. Open an issue to describe a bug or proposed change, then submit a focused pull request with a clear summary.

Before submitting:

- Keep credentials, personal information, private network details, generated packages, and local configuration out of commits.
- Run the relevant checks listed in the README.
- Update documentation when changing setup, configuration, or user-visible behavior.
- Include only data and assets that may be redistributed under their applicable licenses.

By submitting a contribution, you agree that it may be distributed under this repository's GPL-3.0-or-later license.
