# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is unavailable, contact the repository maintainers privately before sharing details publicly.

Do not include live API keys, private keys, internal hostnames, or sensitive indicators in public issues or pull requests.

## Data handling

Indicators sent to the backend may be forwarded to the selected external analysis provider. Review provider terms before submitting confidential or regulated data. The backend's user-agent check is not authentication; restrict network access to the service and configure an appropriate TLS certificate.
